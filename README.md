## 👀 Voir la landing page

- **En local** : ouvre `landing/index.html` dans ton navigateur.
- **En ligne (GitHub Pages)** : le dépôt sert déjà `index.html` à la racine (page de conformité TikTok requise par l'API). La landing est accessible sur `…/landing/`. Pour en faire la page d'accueil sans casser la vérification TikTok, déplace plutôt la conformité dans `/policies/` **après** avoir mis à jour l'URL dans le portail développeur TikTok.
